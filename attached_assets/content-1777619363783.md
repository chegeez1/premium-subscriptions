# BIN Checker  API Documentation

√   Your bank information is safe as we do not store or view any data you entered.

Our BIN Checker API lookup function allows you to automate BIN checker by a simple HTTP GET request. For casual user who is not interested to use API, similar function is available in [BIN Checker](https://www.bincodes.com/bin-checker/) page.

The function will return the result in either XML or JSON format. You can parse both format easily into various programming languages and platforms.

This page will describe on how to use our BIN Checker API and the expected result you will receive from our systems.

As part of system security and protection, you require to have an API key in order to access our API function, which will be given once you [register for API Access](https://www.bincodes.com/users/register/).

## General Request Format

BIN Checker through our API is very simple. What you need to do is make a GET request. Below is the example on hot to make request.

```
https://api.bincodes.com/bin/?format=[FORMAT]&api_key=[API_KEY]&bin=[BIN]

OR
https://api.bincodes.com/bin/[FORMAT]/[API_KEY]/[BIN]/
```

| Input Data | Explanation |
| --- | --- |
| **\[FORMAT\]** | Specify the format of the output. Accept "xml" or "json". |
| **\[API\_KEY\]** | API Key assign to your account. |
| **\[BIN\]** | BIN which you would like to check. |

### 1\. XML Format Example

If you want to get the result in XML format, simply follow the example API request as below,

```
https://api.bincodes.com/bin/?format=xml&api_key=9fc53b3db09ca830488d19546a4fc2a1&bin=515735

OR
https://api.bincodes.com/bin/xml/9fc53b3db09ca830488d19546a4fc2a1/515735/
```

### Expected Result in XML Format

```
<?xml version="1.0" encoding="utf-8" ?>
<result>
  <bin>515735</bin>
  <bank>CITIBANK, N.A.</bank>
  <card>MASTERCARD</card>
  <type>CREDIT</type>
  <level>WORLD CARD</level>
  <country>UNITED STATES</country>
  <countrycode>US</countrycode>
  <website>HTTPS://ONLINE.CITIBANK.COM/</website>
  <phone>1-800-374-9700</phone>
  <valid>true</valid>
</result>
```

### 2\. JSON Format Example

If you want to get the result in JSON format, simply follow the example API request as below,

```
https://api.bincodes.com/bin/?format=json&api_key=9fc53b3db09ca830488d19546a4fc2a1&bin=515735

OR
https://api.bincodes.com/bin/json/9fc53b3db09ca830488d19546a4fc2a1/515735/
```
